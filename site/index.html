FAQ

Frequently Asked Questions

What is No-Leak-MCP?

A guard that sits around an AI agent and stops it from sending secrets out. It reads every outbound message first, and blocks the send if a credential is inside, plain or encoded.

Is this a real vulnerability?

Yes. A poisoned Slack message can tell an AI assistant to leak its keys through a link preview, and it leaves nothing in the channel. Reported as CVE-2025-34072, archived, not patched.

Does it change my agent?

No. It's three plugins that slot in around the agent's tool calls. The agent's own model and loop are untouched, and each check can be turned off on its own.

What does it actually check?

The value, not the destination. Before any send, it decodes the argument, base64, hex, gzip and more, and blocks it if your credential is inside. It doesn't care which service would have fetched the link.

Is anything real at risk in the demo?

No. Every credential is a planted decoy (a canary). A "leak" only counts when the attacker's own server receives and decodes that decoy, never on the model's word.
